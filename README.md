# 📦 CSS Flexbox — מדריך אינטראקטיבי לחוג

מדריך לימודי חי המציג את כל מאפייני Flexbox (הן של המכולה והן של הפריטים הבודדים) עם דוגמאות ויזואליות והסברים בעברית.

## 🎯 נושאים הנלמדים בפרויקט

### 1. מאפייני המכולה (Flex Container):
* **תצוגה:** `display: flex`, `display: inline-flex`
* **כיוונים:** `flex-direction` (`row`, `row-reverse`, `column`, `column-reverse`)
* **מעבר שורה:** `flex-wrap` (`nowrap`, `wrap`), קיצור `flex-flow`
* **יישור על הציר המרכזי:** `justify-content` (`flex-start`, `center`, `flex-end`, `space-between`, `space-around`, `space-evenly`)
* **יישור על הציר המשני:** `align-items` (`stretch`, `flex-start`, `flex-end`, `center`, `baseline`)
* **יישור שורות מרובות:** `align-content`

### 2. מאפייני הפריט הבודד (Flex Items):
* `order` — שינוי סדר הפריטים ללא שינוי ה-HTML.
* `align-self` — דריסת יישור המכולה עבור פריט מסוים.
* `flex-grow` — התרחבות יחסית לתפיסת שטח פנוי.
* `flex-shrink` — הגדרת קצב כיווץ הפריט במקרה של חוסר מקום.
